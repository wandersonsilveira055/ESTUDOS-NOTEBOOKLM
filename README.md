#  Caderno Temático - Mentor Inteligente de Currículos

## Projeto DIO - NotebookLM

Este projeto foi desenvolvido como parte do desafio da DIO utilizando o NotebookLM para criar um caderno temático voltado para análise e otimização de currículos com apoio da Inteligência Artificial.

O foco do projeto foi desenvolver um assistente capaz de analisar currículos, sugerir melhorias, indicar competências relevantes e auxiliar na adaptação do currículo para diferentes vagas da área de Tecnologia da Informação.

##  Objetivos

- Aprender a utilizar o NotebookLM como ferramenta de estudo.
- Criar um assistente especializado na análise de currículos.
- Aprender a elaborar prompts mais eficientes.
- Melhorar currículos para vagas específicas da área de TI.
- Registrar todo o processo de aprendizagem durante o desafio.

- ##  Curadoria de Fontes

As seguintes fontes foram adicionadas ao NotebookLM para fundamentar as respostas da IA:

- 📄 Currículo profissional (PDF)
- 📄 Guia de Elaboração de Currículo (PDF)
- 📄 Descrição de Vagas em TI (PDF)
- 📄 Guia de preparação para entrevistas (PDF)


## 🤖 Engenharia de Prompts

Durante o desenvolvimento do caderno temático, foram utilizados prompts para explorar diferentes aspectos da elaboração e otimização de currículos, sempre utilizando como base as fontes adicionadas ao NotebookLM.

### Prompt 1

**Pergunta:**
> Quais são as melhores práticas para elaborar um currículo competitivo em 2025 e 2026?

**Resultado obtido:**
O NotebookLM apresentou recomendações sobre estrutura, organização das informações, legibilidade, compatibilidade com sistemas ATS e boas práticas de apresentação profissional.

---

### Prompt 2

**Pergunta:**
> Como adaptar um currículo para diferentes vagas da área de Tecnologia da Informação?

**Resultado obtido:**
A IA explicou como personalizar o currículo para diferentes cargos, destacando palavras-chave, competências técnicas e experiências relevantes conforme a descrição da vaga.

---

### Prompt 3

**Pergunta:**
> Quais informações são essenciais para candidatos que buscam a primeira oportunidade na área de TI?

**Resultado obtido:**
Foram apresentadas estratégias para destacar projetos acadêmicos, portfólio, cursos, certificações e habilidades comportamentais, mesmo sem experiência profissional formal.

---

### Prompt 4

**Pergunta:**
> Como otimizar um currículo para aumentar a compatibilidade com sistemas ATS?

**Resultado obtido:**
O NotebookLM recomendou utilizar uma estrutura simples, palavras-chave relevantes, evitar elementos gráficos e priorizar formatos compatíveis com sistemas de recrutamento.

---

### Prompt 5

**Pergunta:**
> Quais competências são mais valorizadas para vagas de Jovem Aprendiz, Desenvolvedor Back-end e Analista de Dados?

**Resultado obtido:**
A IA apresentou as competências técnicas e comportamentais mais requisitadas para cada perfil profissional, auxiliando na personalização do currículo para diferentes oportunidades.

##  Cicatrizes (Troubleshooting)

Durante o desenvolvimento do projeto, o principal desafio foi estruturar prompts suficientemente específicos para que o NotebookLM produzisse respostas alinhadas ao objetivo do assistente de análise de currículos.

Também foi possível observar que:

- A qualidade das respostas aumentou significativamente após a inclusão de fontes específicas sobre currículos, vagas e entrevistas.
- Prompts detalhados produziram respostas mais completas e organizadas.
- A combinação entre diferentes fontes permitiu gerar recomendações mais consistentes e contextualizadas.

### Aprendizados

- A qualidade das fontes influencia diretamente a precisão das respostas.
- Prompts bem estruturados reduzem a necessidade de refinamentos posteriores.
- O NotebookLM pode ser utilizado como uma ferramenta eficiente para organizar conhecimento e apoiar o desenvolvimento profissional.

- ##  Miniguia de Estudo

### Resumo

Durante o desenvolvimento deste projeto, foi possível compreender que um currículo eficiente deve ser personalizado para cada vaga, utilizando palavras-chave compatíveis com a descrição da oportunidade e mantendo uma estrutura simples para facilitar a leitura por sistemas ATS.

Também foi observado que a apresentação dos resultados profissionais possui maior impacto quando baseada em conquistas mensuráveis, projetos desenvolvidos e competências técnicas relevantes.

Além disso, o uso do NotebookLM demonstrou como a Inteligência Artificial pode auxiliar na organização do conhecimento, análise de documentos e apoio à tomada de decisões durante a elaboração de currículos.

##  Glossário

| Conceito | Definição |
|----------|-----------|
| ATS | Sistema utilizado por empresas para filtrar currículos automaticamente. |
| Hard Skills | Competências técnicas que podem ser aprendidas e avaliadas. |
| Soft Skills | Competências comportamentais e interpessoais. |
| Palavra-chave | Termo utilizado pelos sistemas ATS para identificar candidatos compatíveis com a vaga. |
| Portfólio | Conjunto de projetos que demonstra as habilidades do candidato. |
| NotebookLM | Ferramenta baseada em IA utilizada para organizar informações e gerar respostas a partir de fontes fornecidas pelo usuário. |

##  Prompts Reutilizáveis

- Analise meu currículo e identifique pontos fortes e oportunidades de melhoria.
- Adapte meu currículo para esta descrição de vaga.
- Quais competências estão faltando para meu perfil profissional?
- Sugira cursos e certificações para aumentar minha competitividade na área de TI.
- Reescreva meu resumo profissional utilizando uma linguagem mais objetiva.
- Meu currículo está adequado para sistemas ATS?
- Compare meu currículo com esta vaga e apresente um plano de melhoria.
